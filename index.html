How to use these notes

1 · Learn the type

Each DFA type starts with “how to recognise it”, a recipe and the traps. Read these first: they are what you reproduce in the exam.

2 · Try it yourself

Before opening a solution, draw your own DFA on paper. Then test strings in the visualiser and compare state by state.

3 · Quiz

Use 🎯 Quiz me under any DFA to guess whether random strings are accepted. It builds the habit of tracing quickly.
